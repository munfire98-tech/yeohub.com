# 기능 점검 (테스트)

코드를 고치거나 정리한 뒤 **뭐가 깨졌는지 한 번에 확인**하는 도구입니다.

```
php tests/run.php
```

이것만 치면 됩니다. 30초쯤 걸리고, 마지막에 이렇게 나옵니다.

```
  전부 통과했습니다 — 32건
```

하나라도 깨져 있으면 어디가 왜 깨졌는지 알려줍니다.

```
  ✕ 업무수행 기록표에 확인내용 입력칸 4개가 보인다
      /work_log.php 화면에 "name=note_sobang" 이 없습니다
```

## 안전한가요

**실제 파일과 회원 데이터는 건드리지 않습니다.**

`.php` 파일만 임시 폴더로 복사해 그곳에서 시험용 서버를 잠깐 띄우고, 끝나면 폴더째 지웁니다.
`data/` 폴더의 진짜 회원 정보는 읽지도 쓰지도 않습니다. 언제 돌려도 안전합니다.

## 언제 돌리나요

- **파일을 서버에 올리기 직전** — 이게 가장 중요합니다
- 코드를 정리하거나 파일을 지운 뒤
- 새 기능을 넣은 뒤

## 부분만 돌리기

```
php tests/run.php static     문법·링크 검사 (서버 없이, 5초)
php tests/run.php auth       권한 검사
php tests/run.php page       화면이 열리는지
php tests/run.php form       입력칸이 제자리에 있는지
php tests/run.php flow       저장하고 이어지는지
php tests/run.php security   남의 데이터가 보이는지
```

## 무엇을 점검하나요

| 묶음 | 잡아내는 것 |
|---|---|
| **static** | 문법 오류 · 없는 파일로 가는 링크 · 아무 데서도 못 들어가는 화면 · 지워지면 안 되는 기능 |
| **auth** | 비로그인·다른 역할이 남의 화면에 들어가는 것 |
| **page** | 화면이 안 열리거나 PHP 오류가 나는 것 |
| **form** | 입력칸·버튼이 사라진 것 |
| **flow** | 저장했는데 다른 화면에 반영 안 되는 것 |
| **security** | 남의 데이터가 보이는 것 · CSRF 뚫리는 것 · 경로 조작 |

실제로 5곳을 일부러 망가뜨려 시험해봤고, 전부 잡아냈습니다.

## 항목 추가하기

`tests/cases.php` 파일에 한 덩어리 추가하면 끝입니다. **새 기능을 만들 때마다 한 줄씩 넣어두세요.**

**화면이 열리는지 보고 싶을 때**

```php
[
  'group'=>'page', 'name'=>'새 화면이 열린다',
  'as'=>'member',                    // null(비로그인) / member / member2 / agency / admin
  'url'=>'/새화면.php',
  'expect'=>['status'=>200, 'contains'=>['화면에 있어야 할 글자']],
],
```

**버튼이나 입력칸이 사라지지 않게 지키고 싶을 때**

`static` 묶음의 `'한 번 넣은 기능이 사라지지 않았다'` 항목에서 `rules` 에 한 줄 추가합니다.

```php
'새화면.php' => ['꼭 있어야 할 글자', 'name="중요한칸"'],
```

주의: **소스 파일에 그대로 적혀 있는 글자**여야 합니다.
`name="photo_<?=$pk?>"` 처럼 PHP로 만들어지는 건 소스에 없으니 못 찾습니다.
그런 건 위의 `page` 방식으로 실제 화면을 열어서 확인하세요.

**저장이 잘 되는지 보고 싶을 때**

```php
[
  'group'=>'flow', 'name'=>'저장하면 다른 화면에 반영된다',
  'as'=>'member',
  'steps'=>[
    ['url'=>'/저장화면.php', 'post'=>['action'=>'save', 'csrf'=>null, '값'=>'테스트']],
    ['url'=>'/확인화면.php', 'expect'=>['contains'=>['테스트']]],
  ],
],
```

`csrf` 를 `null` 로 두면 알아서 채워 넣습니다.

## 이미 아는 문제

지금 두 가지가 "참고"로 표시됩니다. 실패로는 세지 않습니다.

- **`list.php` 가 없는 파일 3개(write/view/edit.php)로 연결** — 쓰지 않는 화면이면 `list.php` 를 지우세요
- **`sign_check.php` 가 어디서도 연결되지 않음** — 파일 첫 줄에 "확인 후 삭제"라고 적혀 있습니다. 서버에서 지우세요

정리하시면 `tests/cases.php` 의 `'known' => [...]` 줄도 함께 지우세요. 그래야 다음에 같은 일이 생겼을 때 잡힙니다.

## 시험용 회원

점검할 때 이 세 사람이 임시로 만들어집니다. 진짜 회원이 아니라 임시 폴더에만 있습니다.

| 아이디 | 상태 |
|---|---|
| `tester1` | 기본정보·확인내용이 다 채워진 회원 |
| `tester2` | 아무것도 없는 새 회원 |
| `admin1` | 관리자 |

## 서버에 올릴 때

`tests/` 폴더는 **올리지 않으셔도 됩니다.** 내 컴퓨터에서 돌리는 도구입니다.

올리신다면 `tests/` 폴더에 `.htaccess` 를 넣어 웹에서 못 열게 막으세요.

```
Require all denied
```
