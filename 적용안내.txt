건물별 일회성 QR 가입·자동 연결

적용
- 이 묶음은 서버에 직접 반영하지 않은 교체 파일입니다.
- 기존 파일을 별도 백업한 뒤 압축 안의 PHP/JS/CSS 파일을 사이트 루트에 적용하세요.
- invite_vendor 폴더도 그대로 함께 넣어 주세요. 서버 내부에서 QR을 생성하는 라이브러리와 라이선스입니다.
- data 폴더의 기존 회원·건물·결제 기록은 교체하지 않습니다.
- 기존 일반 회원가입은 변경하지 않았습니다. 이메일 인증을 뒤로 미루는 흐름은 이 QR 신규 가입에만 적용됩니다.

매니저
1. 사전등록 건물을 지도에서 선택합니다.
2. '유저 연결 · QR'을 누릅니다.
3. QR을 현장의 유저에게 보여줍니다. 링크 복사도 가능합니다.
4. 가입이 완료되면 QR 창에 연결 완료가 표시되고 건물 목록을 다시 불러옵니다.

유저
1. QR 촬영 후 건물명·주소·담당 매니저를 확인합니다.
2. 아이디, 비밀번호, 이메일과 약관·정보 공유 동의를 입력합니다.
3. 건물·매니저가 자동 연결되고 기존 구독 페이지로 이동합니다.
4. 카드 등록은 토스 화면으로 이동해 진행하며, 완료·취소 시 구독 페이지로 돌아옵니다.
5. 적용 금액과 자동갱신 동의를 확인한 후 직접 구독을 시작합니다. 가입/카드 등록만으로 결제되지 않습니다.
6. 구독 완료 안내에서 이메일을 수정·인증할 수 있습니다. 내 정보와 건물관리 화면에서도 다시 접근할 수 있습니다.

초대 규칙
- 신규 가입용입니다. 기존 계정은 기존 매니저 연결 절차를 이용합니다.
- QR은 30분 유효, 1회 사용입니다. 새 QR 발급 시 이전 QR은 취소됩니다.
- 본인 소유이며 아직 연결되지 않은 사전등록 건물에서만 생성됩니다.
- 건물명과 주소가 저장되어 있어야 합니다.
- 토큰은 32바이트 난수이며 서버 상태에는 토큰 해시로 저장합니다.
- URL의 # 뒷부분으로 전달하여 일반 접근 로그/리퍼러에 토큰이 포함되지 않게 했습니다.
- 초대 링크의 공개 도메인은 invite_common.php의 IQ_ORIGIN에 지정되어 있습니다.
- QR을 가진 사람은 가입 후 해당 건물에 연결될 수 있으므로 현장의 해당 담당자에게만 전달하세요.

이메일
- 인증 전 주소는 pending_email에 보관하고 발송용 email은 비워 둡니다.
- 인증번호 발송만 허용되며 계정 찾기/비밀번호 재설정 및 일반 발송용 주소로 사용하지 않습니다.
- 인증번호 10분 유효, 5회 확인 제한, 재발송 60초 간격/시간당 5회입니다.
- 잘못 입력한 주소는 이메일 확인 화면에서 바꿀 수 있습니다.
- 미인증 상태에서 아이디·비밀번호를 잊은 경우 이메일 복구가 불가능하므로 관리자 확인이 필요합니다.

기존 기능 연동
- 기존 사전등록 기본정보 전달, 프로모션 금액 판정, 월별 업무수행기록 리워드를 재사용합니다.
- 결제 금액은 QR에 고정하지 않고 구독 시점에 기존 서버 정책으로 산정합니다.
- 테스트 프로모션 판정은 59,000원을 확인했습니다. 종료일/정책 변경 시 기존 판정 규칙을 따릅니다.
- 토스 결제키·카드정보·실제 청구 로직을 바꾸지 않았습니다.

검증한 내용
- PHP, JS 및 PHP 내부 스크립트 문법
- 초대 만료/취소/재발급, 타 매니저 발급 거절, 삭제된 건물 거절
- 가입과 연결, 기본정보 전달 경로, 59,000원 프로모션 판정
- 토큰 재사용 거절, 두 프로세스 동시 가입 시 한 계정만 생성
- 회원 파일 저장 실패 상황의 동일 계정 재시도 복구
- 미인증 이메일 분리, CSRF, 인증번호 재발송 제한/잘못된 번호/소모된 번호 거절
- 이메일 발송은 테스트 대체 함수로 검증했으며 실제 메일을 보내지 않았습니다.

적용 후 현장 점검
- 실제 휴대폰 카메라로 QR을 읽어 건물·매니저 표시를 확인하세요.
- 테스트 계정으로 가입 후 기본정보와 연결 상태를 확인하세요.
- 토스 테스트 모드에서 카드 등록 완료/취소 및 구독 후 복귀를 확인하세요.
- 실제 SMTP 인증번호 수신과 이메일 변경 후 인증을 확인하세요.
- 브라우저/휴대폰 화면, 실제 SMTP, 토스 실결제는 이번 작업에서 실행하지 않았습니다.
